파일 저장은 JSON 다운로드예요. 공개 게임에 자동 반영되지 않아요. 테스트는 기본 화력·배터리 무제한이며 실제 진행 기록에 영향을 주지 않아요.

아래 진한 선은 바닥이에요. 확대 후 스크롤로 맵을 이동할 수 있어요. 채우기가 밖까지 번졌다면 실행 취소 후 선의 틈을 막아주세요.
