# PERF-001 · Godot 공통 성능/버전 추적

상태: g40앱 사용자 체감 개선 확인("나쁘지 않아"). 무료웹 실제 플레이 확인 대기. 일정 FPS 유지/모든 멈춤 해결을 완료로 선언하지 않는다.

## 관찰과 원인

2026-11-03 이전 g38 녹화에서 압력 확산 반복 조회가475.9ms/전체619.2ms프레임을 차지했다. g39에서 몸체 자세 스냅샷/재료 즉시 재사용과 잔해 증분 갱신 후 새 영상최악82ms관측(입력은동일하지않음). 이후모래12076개휴면/계산0.3ms인데27.6FPS/렌더CPU참고22ms여서 모래 표시 경로를우선했다. g40은 정지모래32칸구역이미지, 이동모래만개별표시로분리했다. 데이터ID/물리/스킬/수집량과보상유지.

## 검증과 기록

[버전/변경/롤백](../planet-patchup-version-history.md), [현재 버전 원장](../planet-patchup-versions.json), [공통 QA](../qa/2026-11-03-common-g40/README.md). 네이티브앱설치3716, 사용자체감확인과 웹빌드/배포/HTTP/실제플레이를 분리한다. 이패키지의 게임/브라우저/기기실행·테스트·발열검증은사용자담당이며 에이전트는수행하지않았다.

## 후속 관찰

증거없는일시멈춤은사용자요청으로이번조사보류. 재발시맵·스킬·HUD버전·영상부터기록한다. 잔해모두휴면인데개별표시가남는지, 이미지구역갱신누적이계속증가하는지, 활성몸체/지지검사가계속높은지를구분한다. 지지/중력/스킬위력을추정으로먼저낮추지않는다. 미계측값은GPU만의비용이아니다.
