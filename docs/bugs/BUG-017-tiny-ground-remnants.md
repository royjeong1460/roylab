# BUG-017 · 바닥의 작은 건물 잔재가100%완료를 막음

접수:2026-11-11. 상태: 로컬 비교판 수정 · 사용자 확인 대기. 공개 웹/아이폰 미반영.

## 제보와 원인

충분한 능력치인데도 바닥에 붙은1–2픽셀 때문에100%가 되지 않는다는 제보. 기존 release_unsupported는 지면에 닿는 픽셀이 하나라도 있는 연결 그룹을 고정 상태로 남긴다. 한 픽셀은 끊을 내부 연결도 없어서, 연결 손상만으로는 제거되지 않는다. 직접 공격으로 픽셀을 제거하는 경로는 별도다. 이 원인은 소스에서 추적했으며 사용자 장면을 재현하지 않았다.

## 승인된 로컬 변경

사용자는4픽셀 이하 작은 잔재의 자동 파쇄와 건물 덩어리·고정 잔재의 바깥선을 선택했다. 기존 손상 후 연결 검사에서 독립 그룹의 크기를 확인하고,1–4픽셀이면 지면 접촉 여부와 관계없이 정상 수집 픽셀로 전환한다. 살아 있는 힌지의 받침은 보호한다. 지형이나 큰 몸통에 아직 연결된 다리를 임의 제거하지 않는다. 원래 ID를 유지하므로 새 보상을 만들거나 삭제하지 않는다.

바깥선은 사각형 덮개 내부의 공유 경계를 제거해 계산하고 Mesh에 캐시한다. 크림색과 청록색 두 겹이며 수집 픽셀에는 적용하지 않는다. 원본 source/public 패키지·기존 기록과 저장 영역은 유지했다.

## 확인 범위

[로컬 전달 기록](../qa/2026-11-11-local-remnant-outline/README.md)에 소스 패치·패키지 해시·HTTP 결과·롤백을 저장했다. import/compile/export와 정적 파일 전달만 확인했다. 사용자 확인: 바닥의 독립1–4픽셀 자동 파쇄,5픽셀 이상 잔재 유지, 아직 연결된 받침의 안정성, 수집/100%종료/보상과 테두리 가독성·FPS.

사용자 완료 확인: 대기.

## 2026-11-11 로컬 테두리 후속 조정

사용자는 작을수록 색을 진하게 하는 등 더 쉽게 구분되길 요청했다.36픽셀 이하·144픽셀 이하·그 이상으로 테두리 색과 두께를3단계로 나눴다. 고정 건물이 한 Mesh로 묶여 있어도 연결된 시각 덩어리별로 크기를 분류하고, 기존 모양 캐시가 바뀔 때만 갱신한다. 자동 파쇄/물리/보상 변경은 없다. [크기별 로컬 전달 기록](../qa/2026-11-11-local-remnant-outline-size/README.md). 빌드·정적HTTP 확인; 사용자 가독성/FPS 확인 대기.
