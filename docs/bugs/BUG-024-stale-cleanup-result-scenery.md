# BUG-024 · 청소 결과의 과거 배경 연출

- 제보일: 2026-11-16.
- 사용자 제보: “청소 결과에서100프로 하면 이미지 보여지는게 과거 이미지 같다 ? 확인해줘”. 사용자가 실제로 본 문화권·맵은 아직 지정하지 않았다.
- 조사 대상: CURRENT iOS0.5.67(77), 공개 Web `free-0541-66ae4962a822`. 게임·씬·테스트·브라우저 게임·기기 앱 실행 없음.
- 확인한 원인: `app/screens.gd:655`의 일반 결과 분기는 regionIndex<=0에서 `EnvironmentReceipt`를 생성한다. 이 컴포넌트는 `background.gd`를 사용해 옛 arch-building-a/b/c, 계단·분수·벤치와 쓰레기를 조합한다. 결과100%에서도 옛 기물 배치가 보인다. 이 조건은100%에만 적용되는 것이 아니며, 다른 문화권 일반 결과에는 해당 이미지 분기가 없고 보스 chapter에는 상태 문구만 있다.
- 현재 플레이: `CultureBackdrop → CultureRoutePanorama → data/culture_routes.json`이 채택된 문화권·맵별 경관 구간을 사용한다.
- 업적 보상: `RestorationGallery → data/restoration_art.json`은 채택된 전체 경관6장을 사용한다. 이미지6개의 원본 해시가 채택 데이터와 일치한다. 일반6맵+보스 모두100%에서 그림을 해금하는 기존 규칙과 이 결과 썸네일 문제는 별개다.
- 정적 확인: 공개 HTML의 mainPack을 조회하고 공개 manifest·PCK의 압축/해제 SHA256을 검증했다. 공개Web·iOS 패키지에서 관련7개 파일의 JSON 또는 컴파일된 GDScript payload가 동일하다. 설치에 사용한 native PCK는 서명 앱에 포함된 PCK와 바이트가 같다. [증거](../qa/2026-11-16-result-art-audit/evidence.json).
- 기대 수정 방향: 결과 화면 경관도 채택된 해당 문화권/맵의 복원 경관을 사용하도록 일치시킨다. 문화권 전체100% 그림 해금 조건·진행·저장은 유지한다. 이번 요청은 확인이므로 제품 소스·아트·빌드·배포·기기 설치를 변경하지 않았다.
- 조사 당시 상태: 원인 확인 · 미수정. 아래 후속 적용 기록을 따른다.

## 2026-11-16 · 승인 후 결과 연결 수정

사용자가 결과 화면도 현재 맵의 복원 경관으로 교체하고 Web·iOS에 적용하도록 승인했다. 현재 맵ID의 catalog.metadata와 이번 결과 ratio를 기존 CultureBackdrop에 전달한다. 기존 Arch-only 분기를 없애고42캠페인 일반·보스 결과에 적용했다.150px크기·캡션을 유지하고 결과용 geometry만 구성하며 World/물리는 만들지 않는다. 플레이 배경·경관 원본·맵·폰트·크레딧·스킬 시연·경제·저장·업적 해금은 유지했다.

iOS0.5.68(78)은 import/compile/export/Xcode/서명 검증 후 업데이트 설치했고 실행하지 않았다. Web `free-0541-df584b999541`은 공개 배포와15개 정적 HTTP응답·압축 전후 해시 확인을 마쳤다. [전달 기록](../qa/2026-11-16-result-scenery-release/delivery.json)을 따른다. 실제 렌더링·배경 구간·쓰레기·지형·스크롤·저장 연속성은 사용자 확인 대기다.

- 현재 상태: Web·iOS 전달 완료 · 사용자 확인 대기.
