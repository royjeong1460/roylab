# BUG-009 PC 플레이 영역 안쪽의 충돌 경계

- 2026-11-06 PC 로컬 웹의 1-1 아치 골목에서 잔해가 화면 오른쪽 끝에 닿기 전에 직선 경계에서 멈췄다.
- 배경 확장은 카메라가 비추는 범위에 적용됐지만, `world.gd`의 물리 벽과 입력 범위는 원본 맵 너비에 남아 있었다.
- 웹 출동 시 원본 구조물을 가운데에 두고 실제 지면과 격자를 화면 비율에 맞춰 양옆으로 확장한다. `app/play_camera.gd`의 가로 맞춤을 같은 격자에 연결했다. 맵 파일과 저장 형식은 유지한다.
- 격자는 기존 최대 맵과 같은 셀 수로 제한한다. 한도에 도달하거나 출동 중 창을 크게 넓히면 위쪽이 잘릴 수 있으며 드래그로 이동할 수 있다.
- `free-0541-213ff1af4fcc`의 Godot import·컴파일·export와 43개 맵의 화면 범위 정적 계산을 확인했다. 실제 잔해 이동과 공격 입력은 사용자 확인 대기다.
