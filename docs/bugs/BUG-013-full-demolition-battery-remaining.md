# BUG-013 · 전체 파괴 후 배터리가 남으면 종료되지 않음

접수: 2026-11-07. 상태: 2026-11-11 재접수 · 보이지 않는 잔여 조각 조사 중.

## 제보와 원인

사용자는 “100프로인데 배터리가 남으면 그대로 멈춰있어”라고 제보했다. 현재 공용 RunSession은 배터리 소진 때만 working → finishing으로 넘어간다. 픽셀화된 모든 ID가 잔해/회수 목록에 있어도 전환하지 않는다. 기본 폭파는 정적 건물과 몸체만 공격 대상으로 인정하므로 모두 부서진 뒤에는 빈 폭파로 남은 배터리를 쓸 수도 없다. 실제 기기 상태를 읽거나 재현한 것은 아니다.

## 수정

공용 campaign/run_session.gd의 종료 점검을 배터리 소진 또는 전체 픽셀화로 확장한다. 초기 총 픽셀 수가 양수이며 잔해 수+이미 회수된 ID 수가 초기 총수 이상인지 정수로 판정한다. 화면에 반올림된 퍼센트, 남은 조각 수나 지형은 조건으로 사용하지 않는다. 배열/딕셔너리의 size만 읽어 매 프레임 전체 픽셀을 탐색하지 않는다.

수집 준비·안정 대기·중앙 흡수·70/80/90/100% 축하·결과 페이드·정산·배터리 수치·스킬 위력은 기존 경로를 재사용한다. 튜토리얼·일반맵·보스 모두 같은 점검을 사용한다. 남은 배터리는 0으로 변경하지 않는다.

## 확인 범위

소스 추적에서 원인을 확인했다. 사용자 지침에 따라 게임 테스트·씬·브라우저·기기 앱은 실행하지 않는다. 컴파일·패키지·배포·설치 결과는 전달 기록에 추가한다. 런타임 수정 완료 판정은 사용자 확인 대기다.

사용자 확인: 배터리를 남긴 채 전량 파괴 → 자동 수집/100% 연출 → 결과; 일부만 파괴한 상태에서는 계속 공격 가능; 배터리 0에서는 기존 수집; 잠시 일시정지 후 복귀해도 종료/보상 중복 없음.

## 2026-11-11 · 1-3, 배터리41% 상태에서 종료되지 않음

사용자는 방금 설치한 아이폰0.5.58에서 블록을 모두 깬 것으로 보이지만 배터리41% 상태로 종료되지 않는다고 제보했다. 흰 테두리 잔재도 보이지 않았고, 놓친 것이 있는지 확인하려고 사용한 위성도 보이지 않았다고 답했다.
