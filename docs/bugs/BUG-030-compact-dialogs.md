# BUG-030 · 장착 상태와 짧은 팝업의 여백

강화 → 스킬에서 장착한 항목에 민트색과 체크가 겹쳤다. 일시정지에서는 옵션과 피드백이 한 줄씩 놓였고, 패널은 첫 배치 후 글줄 높이가 바뀌어도 다시 맞춰지지 않았다. 다시하기·조기 회수 등 공용 팝업은 본문 길이와 관계없이 화면 높이의 72%(최대 560)를 사용했다.

장착 문구를 중앙에 맞추고 중복 체크를 없앴다. 일시정지는 짧은 보조 동작을 한 줄로 묶었다. 짧은 창은 실제 내용 높이로 중앙에 배치하고, 긴 내용은 안전 영역 안에서 스크롤한다. 경관 보상 및 일반 보기에서만 불필요한 높이를 줄이고 확대 보기와 전체 갤러리는 기존 크기를 유지한다.
