# 버그 기록

사용자 제보 → 재현·원인 확인 → 수정·검증 → 사용자 확인 대기 → 완료 순서로 관리한다.
각 기록에는 제보일, 실행판과 재현 조건, 기대 동작, 원인, 변경 파일과 변경 이유, 실제 수행한 검증, 남은 확인, 사용자 완료 확인을 남긴다.
사용자가 완료를 확인하기 전에는 완료로 표시하지 않는다. 재발하면 같은 기록을 다시 열고 재현 조건과 후속 변경을 추가한다.
