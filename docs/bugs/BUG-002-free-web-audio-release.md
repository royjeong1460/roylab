# BUG-002 · 무료 공개 웹 사운드 미반영

- 제보일: 2026-10-29.
- 사용자 제보: “사운드 무료버전 웹버전엔 안올라갔다”.
- 상태: 공개 배포 검증 중.
- 대상: https://roylab.pages.dev/planet-patchup/play/ 의 무료 웹버전.
- 재현: 공개 페이지를 열고 Options를 눌러 첫 입력을 발생시켜도 v10 음악과 신규 10종 효과음 파일이 요청되지 않는다. 공개 스크립트는 `free30-CMukCsNr.js`다.
- 기대: 무료 웹에서도 v10 음악과 승인한 신규 효과음 10종을 재생하고, 기존 Sound 설정을 따른다. 패시브 알림과 패시브 추가 폭파음은 제외한다.
- 원인: 로컬 게임·웹 빌드·유료 iPhone 앱에는 반영했지만, 공개 배포 브랜치는 사운드 연결 전인 `09e5422`에 머물러 있었다.

## 수정 범위

- 공개된 `origin/main`에서 분리한 배포 작업 폴더에 사운드 소스와 자산, 관련 검사만 옮긴다.
- 현재 공개된 사막 홈과 게임 아트, 분석·피드백 설정, 저장 키와 진행은 유지한다.
- 무료 게임을 빌드하고 공개 진입 파일을 생성한 뒤 GitHub → Cloudflare 배포 결과와 실제 공개 사이트의 파일 요청을 확인한다.
- 기본 작업 폴더의 다른 미완성 수정과 비공개 검증 자료는 배포에 포함하지 않는다.

## 검증 기록

- 공개 배포 전 브라우저에서 v10 M4A 및 신규 WAV 요청이 없음을 확인했다.
- 배포 기준 `09e5422`의 사이트 검사 5개 및 캠페인 검사 136개가 통과했다.
- 사운드 적용 후 캠페인 검사 142개, 무료판 검사 66개, 사이트 검사 5개가 통과했다.
- 무료 Vite 빌드와 Next.js 정적 export 빌드가 통과했다.
- v10 M4A와 신규 WAV 10개의 SHA-256이 소스·Vite·public·정적 export 결과에서 모두 일치했다.
- 사운드 배포 범위 밖의 public 파일 137개가 그대로 유지됐다. 공개된 아트와 분석·피드백 스크립트도 동일하다.
- 공개 배포 완료 여부와 공개 주소의 실제 음악·효과음 요청 확인은 아래 사용자 확인 전에 별도로 기록한다.

## 사용자 확인

배포 후 사용자의 실제 재생 확인을 기다린다. 확인 전에는 완료로 표시하지 않는다.
