# BUG-006 튜토리얼 배경과 안내

- 제보일 2026-11-06. 로컬 Godot 무료판에서 Arch Quarter의 First Arch를 열면 배경 양옆과 바닥 타일 아래에 단색 띠가 보이고, 작은 안내 문구가 하늘색과 겹쳐 읽기 어렵다. 다른 지역에도 연습 진입이 노출된다.
- 맵에 맞춘 카메라가 맵 바깥을 비출 때 배경은 물리 맵 경계에서 잘렸고, 바닥 타일은 28 유닛만 채웠다. 안내는 배경 패널 없이 표시됐으며 지역 선택과 관계없이 튜토리얼 버튼을 생성했다.
- 튜토리얼에 한해 카메라가 볼 수 있는 영역까지 배경과 타일을 확장했다. 안내 카드의 글자와 대비를 키우고 폭파의 배터리 소모를 명시했다. 튜토리얼 진입과 강화 안내는 Arch Quarter로 제한했다. 전투 상단은 배터리와 일시정지만 표시한다.
- `app/play_camera.gd`, `app/play_view.gd`, `background.gd`에서 배경 표시 영역을 조정했다. `app/screens.gd`, `campaign/journey.gd`, `campaign/tutorial.gd`, `data/locale-ko.json`에 UI, 진입 조건과 안내를 반영했다. Godot import·컴파일·웹 export와 패키지 해시를 확인했다. 로컬 빌드는 `free-0541-762569787e5f`다.
- 사용자 확인 대기. 같은 화면 크기에서 배경과 안내의 가독성을 비교하고, 2지역 이후 튜토리얼 진입 버튼이 표시되지 않는지 확인한다.

## 2026-11-06 PC 전체 맵 후속

- 튜토리얼 외에도 PC에서 가로로 넓은 플레이 영역에 단색 띠가 남는다고 제보했다. 1지역 일반 맵에는 배경 확장 경로가 없었고, 2~6지역의 풍경과 지면도 맵 경계에서 잘렸다.
- `app/play_view.gd`와 `app/play_camera.gd`에서 모든 현장에 동일한 표시 범위를 전달한다. `background.gd`는 1지역 배경과 바닥을 확장한다. `presentation/culture_backdrop.gd`와 `presentation/culture_ground.gd`는 2~6지역 원경을 가장자리에서 반사해 잇고 지면 높이와 타일을 양옆으로 이어 그린다.
- Godot import·컴파일·웹 export, 43개 맵의 화면 범위 정적 계산과 패키지 해시를 확인했다. 로컬 빌드는 `free-0541-e5c31e572309`다. PC 브라우저에서 일반 맵과 보스 맵의 가장자리 연결은 사용자 확인 대기다.
