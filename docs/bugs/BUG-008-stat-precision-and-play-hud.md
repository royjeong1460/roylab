# BUG-008 강화 소수 표시와 전투 HUD

- 2026-11-06 PC 로컬 Godot 웹의 자원 정제 Lv 1 → 2 상세에서 다음 값이 `8.48528137423857%`로 표시됐고, 회수 대기 화면에서는 배터리 퍼센트와 일시정지 버튼의 세로 정렬이 어긋났다.
- `campaign/economy.gd`의 설명용 포맷이 소수 14자리였고, `app/screens.gd`는 상단 요소의 세로 좌표를 각각 정했다. 표시용 소수를 최대 두 자리로 제한하고 상단 중심선을 통일했다.
- 회수 대기 버튼은 `지금 회수`로 바꾸고 하단 상태 문구 옆에 배치했다. 대기를 끝내고 회수를 시작하는 조건은 기존과 같다.
- 로컬 빌드 `free-0541-51a70d27907f`에서 import·컴파일·export와 정적 패키지를 확인했다. PC 화면과 버튼 동작은 사용자 확인 대기다.
