# 고물 바람골 고정 스테이지와 수동 맵 편집

목표: 이름 있는 6개 현장과 Boss를 순서대로 공략하고 최고 회수율과 올클리어를 남긴다. 물리와 강화 수치는 그대로 유지한다.

## 1. 진행 구조
- 시작 → 맵 목록. 이름 왼쪽, 최고 회수율 오른쪽. 1번만 처음 열림.
- 한 판에서 70%를 회수하면 다음 단계 해금. 계속 플레이 가능, 100%는 올클리어.
- 재도전해도 최고 기록 감소 없음. 기록은 회수량/총량으로 저장하여 반올림으로 해금하지 않는다.
- 기존 부품·강화·보스 보상 유지. 기존 이력에서 동일 맵의 최고 기록을 복원하고 없는 기록은 새로 시작한다.
- 튜토리얼은 첫 맵 진입 전 기존 조작 연습과 첫 강화로 유지. 다음 출동은 1번 맵 선택.
- 정산·저장 실패, 다른 탭 초기화 방지 로직 유지. 새 스키마는 이전 탭의 덮어쓰기를 막는다.

## 2. 맵 메이커
- 별도 페이지에서 1~6/Boss 선택, 5색 픽셀 그리기/지우기/선/사각형, 실행 취소.
- 브라우저 초안 저장/불러오기, JSON 가져오기/내려받기, 현재 맵 바로 물리 테스트.
- 초안은 공개 맵과 실제 게임 저장에 영향 없음. 테스트는 별도 임시 진행 사용.
- 공중에 고립된 픽셀·겹침·한도 등 기존 맵 검사 유지, 오류를 화면에 표시.
- 공개 반영은 검증된 JSON을 코드에 반영하는 별도 작업. 미래 구역은 같은 데이터 구조로 컬러를 바꾸는 방향이며 이번에는 추가하지 않는다.
