# 파괴 특성 강화 초안 · 2026-11-07

사용자는 전체 맵 픽셀을 줄인0.5.52(62)의 방향을 채택하고, 이전에 분류한 파괴 수치 강화를 다시 정리하도록 요청했다. 이 문서는 기획 초안이다. 게임 수치·가격·세이브·배포물은 변경하지 않는다. 공개 웹 배포는 별도 요청 전까지 기존 상태다.

## 기준과 설계 선택

- 맵 기준: 전체43개 캠페인/튜토리얼의 픽셀608,590 →391,069, 원본 대비35.74% 감소. 별도 fallback도 축소. 기둥 최소 폭과 모듈 연결을 유지한0.5.52 소스다.
- 사용자 확인: 축소 맵 방향으로 계속 진행하기로 결정. 정량 FPS·입장 시간·모든 맵 무결함이 검증됐다는 뜻은 아니다.
- 2026-11-07 사용자 선택 확정: **현재 수치를 첫 목표 상한으로 둔다.** 신규 진행의 시작값을 완만하게 낮추고 현재 파괴 보정값에 도달하도록 성장시키는 방향이다.
- 아래 표의 시작값·10단계 구성·단계별 증가폭·비용·해금 시점·세이브 승계는 계속 초안이다. 현재 수치를 기본값으로 놓고 추가로 증폭하는 방향은 이번 첫 구간에 채택하지 않는다.

## 새 공통 강화5종

패시브 장착2칸과 광역 스킬 장착은 그대로 별도다. 아래 특성은 장착을 교체하는 스킬이 아니라 계정 공통 영구 강화로 제안한다. 충격파의 직접 파쇄 반경/힘, 블랙홀의 흡인/마모 수치와도 구분한다.

단계 구성은 미구매L0부터L10까지를 제안한다. 목표 수치는현재0.5.52에 이미 적용된 값으로 확정됐고, 그 목표를10단계에 배치하는 방식과 시작값은 아직 제안이다. 예상 효과를 검증 결과로 표현하지 않는다.

내부 균열의 설명용 강도는 `0.04 / (0.04 - 0.002L)`이므로 레벨당 같은 비율로 오르는 표시는 아니다. 낮은 낙하 접촉의 최소 속도14와 활성화 곡선은 별도로 유지하고, Fall Breaker는 내부 균열 심화 시작/최대 속도만 제어하도록 분리하는 안이다. 시작 속도가 최대 속도보다 작도록 두 값을 같은 레벨에서 산출한다.

L10 이후 새 물리 계수의 무한 증가는 이번 범위에 넣지 않는다. 기존 무기·스킬의 무한 강화는 그대로다. 새 특성의 첫10단계보다 높은 상한은 최대 장비·대량 동시 붕괴의 사용자 성능 확인을 거쳐 별도 결정한다.

## 연쇄 조건과 기본 물리

연쇄 단계 보정은 현재처럼 `기본 계수 × (1 + 0.25 × (단계−1))`이다. 예를 들어 기본6일 때6/7.5/9…, 기본10일 때10/12.5/15…이다. 최대8단계, 다른 원래 건물 판정, 반복 충돌쌍 제외, 바닥·같은 원래 건물 제외, 최소 질량/접근 속도/접촉 속도 조건은 유지한다. 강화로 발동 조건을 무제한 완화하지 않는다.

다음 항목은 강화 상품으로 만들지 않는 안이다.

- 기울어짐 보조: 현재 받침이 있는 중력 방향 회전 보조를 기본 동작으로 유지. 중력·질량·회전 관성·공중 낙하·정지 조건을 구매 유무로 바꾸지 않는다.
- 조각 수 제한/초과 픽셀화: 성능·정상 파괴를 위한 기본 처리로 유지. 강화 전에는 조각 제한 때문에 파괴가 멈추는 구조로 만들지 않는다.

## 기존 강화와 중복 방지

- 기존 Debris Processing(잔해 처리)은 `1 + 0.08√L`로 떨어진 몸체의 파쇄 예산/직접 픽셀화 허용량을 늘린다. 기존 레벨·구매 내역·비용을 즉시 없애거나 이름만 바꿔 다른 효과로 대체하지 않는다.
- 새 Impact Breaker는 속도 활성화 곡선, Core Fracture는 결합 비용, Crack Spread는 거리로 역할을 구분한다. 잔해 처리와 같은 전체 피해 배율을 또 추가하지 않는다.
- 새 계수는 현재 상수의 자리에 절대값으로 들어간다. 예를 들어 연쇄10에 다시 새10을 곱해100으로 만들지 않는다. 파쇄 예산 배율도 기존 단계에서 한 번만 적용한다.
- 연쇄와 일반 낙하는 현재처럼 충돌당 별도 분기다. 모든 특성을 한 충돌에 단순히 곱해 최종 피해를 표시하지 않는다.
- 블랙홀의 중심 마모/휘젓기와 충격파의 직접 힘/반경은 기존 강화로 유지한다. 새 특성은 해당 물리 충돌/낙하가 실제 발생했을 때 적용되며 모든 공격에 항상 동일한 배율을 주지 않는다.

## 해금과 비용 초안

UI와 비용은 아직 구현·검증하지 않은 제안이다. 현장 클리어는 기존70% 기준이다.

| 강화 | 해금 제안 | 첫 구매 비용 제안 |
| --- | --- | ---: |
| Impact Breaker | 1-1 클리어 | 조각200 |
| Fall Breaker | 1-3 클리어 | 조각400 |
| Chain Amplifier | 1지역 보스 클리어 | 조각800 |
| Core Fracture | 2지역 보스 클리어 | 조각1,200 |
| Crack Spread | 3지역 보스 클리어 | 조각1,600 |

새 특성의 n번째 구매 비용은 `10 × ceil(첫 비용 × 1.10^(n−1) / 10)` 초안이다. 기존 충격파·블랙홀·배터리·수집·스킬 비용을 일괄 변경한다는 뜻이 아니다. 실제 비용은 축소 맵에서 기록한 회수량과 업그레이드 간 판 수로 조절해야 하며, 광고 시청을 클리어나 기본 붕괴의 필수 조건으로 만들지 않는다.

## 기존 진행과 검증 순서

현재 플레이어에게는 하드코딩된 목표 수치가 이미 제공되고 있다. 이를 신규 강화L0로 바꾸면 새 구매를 하지 않은 기존 세이브가 약해진다. 기존 효과를 보존하는 승계 규칙을 먼저 정해야 한다. A안이라면 기존 진행에 목표 효과를 승계하고, 새 밸런스는 별도 신규 테스트 저장에서L0부터 확인하는 방식을 제안한다. 이번 문서 작성에서 세이브를 수정하거나 초기화하지 않는다.

1. 현재 축소 맵을 기준으로 초반 붕괴의 재미를 먼저 확인한다.
2. 충격 파쇄/연쇄 증폭을 먼저 비교하고 나머지는 현재값으로 고정한다.
3. 낙하 파쇄의 두 문턱을 비교한다. 내부 저항과 전파 범위를 동시에 바꾸지 않는다.
4. 내부 균열/확산을 각각 비교한 뒤 전부 조합한 최고 강화에서6지역 보스의 동시 붕괴·활동 모래를 확인한다.
5. 기록된 회수량·한 판 시간·업그레이드 간 판 수를 기준으로 비용을 조정한다. 초안만으로 목표 플레이 시간을 보장하지 않는다.
