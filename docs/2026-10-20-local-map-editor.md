# 로컬 맵 메이커 — 2026-10-20

## 확정 범위

- 새 맵 → 로컬 JSON 불러오기 → 편집 → 로컬 JSON 저장.
- 사각형, 삼각형, 원, 타원, 다각형: 테두리/채운 도형 선택.
- 선 및 붓 두께 1~6픽셀. 지우개는 1×1, 3×3, 5×5, 7×7, 9×9, 11×11 정사각형.
- 같은 색으로 연결된 영역을 4방향 탐색으로 채우기. 대각선 테두리는 4방향 연결을 유지해 내부 채우기가 새지 않도록 한다.
- 구조물 및 영역 선택, 이동, 크기 조절, 실행 취소 유지.
- 물리·밸런스 및 공개 배포는 이번 변경 범위에 포함하지 않는다.

## 사용법

로컬 서버 `npm exec vite -- --host 127.0.0.1 --port 8780` (demos/planet-patchup).
편집기: http://127.0.0.1:8780/free30-map-editor.html

새 맵은 이름과 크기를 입력한다. 가로 64~1,024칸, 바닥 위 세로 84~1,012칸.
도형은 드래그, 다각형은 꼭짓점을 클릭한 후 완성 버튼/Enter. Esc로 작성 중 다각형을 취소한다.
파일 저장은 브라우저 다운로드이며, 파일 불러오기는 시스템 파일 선택기를 사용한다. 파일 위치·동일 이름 처리 방식은 브라우저 설정에 따른다.

## 데이터 경계

작업 파일 `*.map.json`은 format=planet-patchup-map, version=1, name, width, height, worldHeight, cells(0~5 색상)의 편집 문서다.
빈 맵, 아직 바닥에 연결하지 않은 구조물, 게임 내보내기 한도를 넘은 작업도 저장 가능하다.
입력은 4MB 이하이며 크기, 배열 길이, 각 색상 값, 이름을 검증한다. 기존 게임 맵 JSON도 가져올 수 있다.

폭파 테스트와 `*.game.json` 내보내기는 기존 validateSite 조건(바닥 연결, 1~20,000픽셀, 압축 사각형 240묶음)을 유지한다.
테스트는 전용 local-editor-preview 초안을 쓰며 기존 스테이지 초안과 플레이어 저장 데이터는 덮어쓰지 않는다.
새 도형도 최종적으로 색상 픽셀 배열로 저장한다. 도형 객체 레이어가 아니라 연결된 픽셀/선택 영역 단위로 이동·크기 변경한다.

## 검증

- 도형 테두리 안 채우기, 오목 다각형, 두께/지우개 가장자리 처리, 문서 왕복 및 잘못된 문서 거부, 미완성 저장/게임 검사 분리 테스트.
- 로컬 브라우저에서 새 맵, 사각형·삼각형·원·다각형, 채우기, 두께, 3×3 지우개(정확히 9픽셀 감소) 확인.
- 실제 파일 다운로드 → 빈 맵 생성 → 같은 파일 다시 불러오기: 이름/크기/758픽셀 복원 확인.
- 작성한 맵이 배터리 무제한 폭파 테스트 화면에 나타나는 것 확인.
- 구조물 이동 및 가로 32→34칸 크기 변경(758→787픽셀) 확인. 입력 중 크기 값이 재렌더링에 덮이는 문제도 회귀 검사 추가.
- 실제 모바일 기기 테스트는 하지 않았다. 이 편집기는 로컬 데스크톱 제작용이다.


## 최대 맵 크기 확대 후속 변경

- 로컬 편집기 최대 가로 1,024 × 바닥 위 세로 1,012, 바닥 아래 포함 전체 격자 1,024 × 1,024.
- 화면 확대 최솟값 1배. 초안 파일 제한은 최대 크기 픽셀 배열을 저장할 수 있도록 4MB로 확대.
- 기존 공용 생성기/가져오기 검증의 기본 상한 256은 유지. 편집기에서만 maxDimension=1024를 명시한다.
- FreeRun이 초기화 중 원본 World와 고정본 World를 모두 경유하므로 두 world.js의 격자 크기 상한만 256→1024 변경. 중력·파괴·폭파·마찰 수식은 변경하지 않았다. 기존 스냅샷은 수정하지 않고 이전 물리 기준으로 보존한다.
- 실제 건물 픽셀 20,000개와 사각형 압축 묶음 240개 제한은 게임 테스트에 계속 적용한다.
- 자동 검사: 최대 맵 문서 왕복/상한 초과 거부, 원거리 좌표(984,1004) 폭파 및 블랙홀, 픽셀 보존/유한 수치 확인.
- 브라우저: 최대 크기 빈 맵 생성, 1배 축소, 2MB를 넘는 실제 JSON 다운로드 및 다시 불러오기 확인.
- 대형 맵의 실기기 프레임 속도/발열은 미측정. 공간 확대는 모든 칸을 건물로 채워도 원활하다는 보장이 아니다.

## 로이랩 공개판 연결

사용자 후속 요청에 따라 개발 서버 전용 표시를 해제하고 공개 게임 시작 화면의 강화/맵 아래에 ‘맵 제작 ↗’ 링크를 추가했다. 최신 로컬 파일 편집 기능과 크기 확장도 함께 공개 빌드에 포함한다. 호스팅된 편집기에서도 작업 파일은 사용자 컴퓨터로 다운로드하며 맵 업로드/서버 저장은 없다.
