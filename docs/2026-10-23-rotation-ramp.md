# 1·3·5칸 / 점진 회전 실험

공개 경로: /games/planet-patchup-ramp/
이전 /planet-patchup-bearing/ 및 motion/support/ideas/무료/유료 배포물과 저장값은 유지한다.

## 확정값
- 기둥 두께1/3/5칸. 같은 상부 건물, 단독 보기 및 중앙/무거운 중앙 하중 비교.
- 회전 시작 시1배,2.5초 후3배,5초 후5배. 이후5배 유지.
- 시간은 조각별 시뮬레이션 시간. 일시정지 제외, 분열한 파편은 부모의 진행시간 상속.
- 중력1배와 기존 속도 제한 유지. 각속도를 직접 곱하지 않고 기준 관성을 배수로 나누므로 실제 회전 속도5배를 보장하는 모델은 아니다.
- 회전이 없던 조각은1배로 대기하며, 회전이 감지된 뒤 증가를 시작한다. 직접 충돌로 회전하기 시작한 파편에도 적용한다.
- 시작 후 먼저 착지할 수도 있으며,5초 동안 반드시 공중에 머무르게 하지는 않는다.

## 코드 경계
RampWorld는 BearingWorld 위에 관성 조절만 추가한다.1배 관성을 조각별로 저장해 매 프레임 중복 곱셈을 방지한다. 설정 적용도 공유 motion 함수에 rotation1을 전달한 뒤 별도의 상한으로 처리한다.

가로400칸 비교 맵은 기존1024칸 맵 편집기 검증 경로를 사용한다. 카메라 밖 여유 공간을 포함한 물리 맵은656칸이다. 기존 일반 맵 검증 제한은 변경하지 않는다.

## 검증
- 점진 회전 테스트5개 통과: 동일한 상부 구조, 맵 저장/불러오기, 회전 시작/2.5초/5초/상한, 일시정지, 파편 상속, 재설정 중복 방지, 전용 저장 키.
- 실제 확장 맵과 화력 설정에서1200프레임 실행:3칸/5칸 시험체 유지, 픽셀 수 보존, 물리값 유한.
- 기존 bearing 테스트8개 통과.
- 로컬 웹에서 현재 회전 반응1.08배와5.00배 표시, 최대5배 설정창, 모바일 맵 선택 확인.
- 실제 iPhone 기기 성능/조작감은 이번 자동 검증 범위에 포함하지 않았다.
