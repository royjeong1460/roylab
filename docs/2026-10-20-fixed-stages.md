## 편집

`free30-map-editor.html`: 맵 선택, 픽셀 그리기·지우기, 선·사각형, 5색, 확대, 실행 취소, 로컬 초안 저장/불러오기, JSON 가져오기/내려받기, 별도 탭 테스트. 대각선은 4방향 연결 판정에 맞춰 이어서 그린다.

초안은 현재 브라우저/주소에서만 저장된다. JSON 다운로드가 외부 백업이며 다른 기기로 공유할 수 있다. 테스트는 해당 초안을 불러와 기존 물리 + 기본 화력 + 폭파/블랙홀 + 무제한 배터리로 실행한다. 실제 진행은 읽거나 쓰지 않는다. 게임에 공개 반영하려면 내려받은 JSON을 검증해 코드의 맵 데이터에 반영하는 작업이 필요하다. 편집기에서 저장했다고 모든 플레이어의 맵이 바뀌지 않는다.

기존 엔진 입력 제한: 20,000픽셀, 사각형 묶음 240개, 최대 256×256, 모든 구조물은 4방향 연결로 바닥에 이어져야 한다. 실시간 편집 중에는 임시 공중 구조가 가능하지만 저장/테스트 전 유효성 검사 필요.

## 사용자 확정 후 보완

- 70%에 도달하면 다음 맵 해금 기록을 즉시 저장하고 계속 플레이한다. 부품 보상과 최종 최고 기록은 정산 때 저장한다. 저장 실패는 재시도하며 다른 탭에서 초기화된 과거 출동 기록은 저장하지 않는다.
- 맵 메이커에 구조물 클릭 선택(4방향 연결 전체), 영역 선택(일부 구조), 드래그 이동, 오른쪽 아래 손잡이 크기 조절, X/Y/가로/세로 숫자 입력 추가. 픽셀 단위로 정렬되며 다른 구조물과 겹치거나 경계를 벗어나면 적용 거부. 이동·크기 조절도 실행 취소 가능.
- 크기 변경은 기존 색상의 최근접 픽셀 확대로 처리한다. 연결이 끊기는 편집은 가능하지만 기존 저장/테스트 전 연결 검사로 알린다. 이번 MVP는 객체 레이어를 별도로 유지하지 않고 현재 픽셀에서 구조물을 선택한다.
- 브라우저에서 연결 구조물 선택, X 이동, 숫자로 너비 확대, 부분 영역 선택, 손잡이로 너비/높이 축소, 실행 취소 및 초안 복원 확인.

## 일반 현장 자유 선택 — 2026-10-20 후속

- 일반 현장 1~6은 처음부터 선택 가능. 순서 제한을 없앤다.
- Boss만 일반 현장 6곳 각각의 최고 회수율이 70% 이상일 때 해금한다. 서로 다른 판에서 모은 기록의 합산이 아닌 현장별 한 판 최고 기록을 사용한다.
- 70% 달성 후 현재 판은 계속 진행하며 100% 올클리어에 도전 가능하다. 마지막 일반 현장의 70% 체크포인트가 저장되면 보스가 즉시 열린다.
- 기존 최고 기록/강화/부품 저장 형식은 유지한다. 초기화 시 일반 현장은 여전히 모두 열리고 보스만 잠긴다.
- 결과의 해금 안내는 보스가 처음 열린 판에만 표시한다. 목록/팁/시작 안내에 순차 해금 문구를 제거하고 달성 현장 수를 표시한다.
- 검증: 비순차 6→3→1→5→2→4 진행, 마지막 현장 70% 미만에서 보스 잠금, 70% 달성 후 보스 입장, 마지막 현장 진행 중 체크포인트 해금, 기록 보존/초기화/이전 저장 복원.
