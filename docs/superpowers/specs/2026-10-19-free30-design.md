# 무료 첫 구역 — 30분 목표, balance v1

사용자가 승인한 폭파 시작 → 랜덤 현장 회수·강화 → 블랙홀 해금 → 수동 보스 도전 흐름을 Roylab에 공개한다. 기존 데모 및 저장 데이터는 유지한다. 별도 `/games/planet-patchup-free/`와 저장 namespace를 사용한다.

- 첫 폭파 위력과 배터리 60, 흡입 80/초를 유지. 폭파 힘 강화는 +17.5%, 반경은 +0.25칸. 모든 성장 수치와 비용은 balance.js에 둔다.
- 블랙홀 중심 휘젓기, 마모 상한을 별도 강화. 실제 접촉·미끄러짐에서만 1배부터 상한으로 가속. 본편 설계 최대 10배, 이번 무료 구역은 작은 단계로 제한한다.
- 실험실의 무제한 배터리/설정 UI는 제외. 테스트한 10배 속도 파괴 증가, 조각 상한 넘침 파괴 및 접촉 마모 물리를 동결 복사해 기존 공개 버전에 영향을 주지 않는다.
- 70% 회수한 쌍봉 철탑 보스가 무료 구역 엔딩. 도전 버튼은 처음부터 열려 있고, 시간·강화 횟수로 막지 않는다. 실패해도 회수 부품은 남는다.
- 마지막 배터리 1회 사용과 종료 후 최대 10초 수집, 정산 후 작업장 우선 노출을 유지한다.
- 모바일 전체 폭, 오프셋 조준/손 떼기 공격, 두 손가락 이동·확대, 미니맵, 민트색 수집물 유지.
- 30분은 첫 플레이 목표이며 강제 지연이 아니다. 실제 물리 도달성 검증과 경제 가정 기반 시간 추정은 구분해서 기록한다. 숙련자는 빨리 끝낼 수 있다.
- 강화·보스 시도·회수량·작업 시간은 로컬 기록으로 내보낸다. 결제/원격 분석/유료 콘텐츠는 이번 범위 밖이다.
