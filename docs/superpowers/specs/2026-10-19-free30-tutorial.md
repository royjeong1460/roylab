# 무료 첫 구역 튜토리얼

승인된 흐름: 조준점 원형 그라데이션 → 기둥 폭파 → 실제 붕괴/잔해 수집 → 배터리 소진과 마무리 수집 → 수거량 정산 → 첫 강화 1회 → 다음 현장. PC는 누르는 순간 폭파, 모바일은 기존 왼쪽 위 조준점에서 손을 뗄 때 폭파한다.

첫 저장의 일반 출동만 312픽셀 작은 간판 연습 맵을 사용한다. 받침을 실제로 폭파하면 기본 물리로 떨어지고, 나오는 민트색 잔해를 기존 자동 흡입으로 모은다. 안내는 폭파 입력만으로 진행하지 않고 실제 조각 또는 잔해가 생긴 것을 관찰한다. 빗나가면 기둥 안내를 유지한다. 전투나 수집 물리 수치는 바꾸지 않는다.

강화 비용은 기존 80부품이다. 정산 후 구매 가능하면 첫 폭파 반경 강화 하나를 보여주고, 구매 성공 후 다음 현장 버튼으로 안내한다. 부족하면 획득한 부품을 보존하고 연습 현장에서 더 모을 수 있다. 보상이나 픽셀을 가짜로 추가하지 않는다. 첫 강화 완료 전후 상태는 같은 안전한 저장 트랜잭션으로 기록한다.

기존 저장은 튜토리얼 완료로 해석해 강제 재교육하지 않는다. 홈의 '조작 연습 다시 하기'로 연습을 재생할 수 있으며, 안내 건너뛰기를 제공한다. 기존 수동 보스 입장은 유지하며, 보스 도전을 고르면 튜토리얼 대신 자유 진행한다. 재연습은 별도 보너스 없이 실제 회수량만 정산한다.

하단에는 실제 사용 입력에 맞춘 짧은 팁을 모든 판에서 9초 간격으로 순환한다. 카메라 이동/확대, 자동 수집, 강화, 복귀와 보스 목표를 안내한다. 배터리 마무리와 70% 달성 알림이 팁보다 우선한다. 일시정지 중 타이머는 흐르지 않는다. 그라데이션은 입력을 가로채지 않으며 모션 감소 설정에서 표식 애니메이션을 끈다.

검증: 저장 마이그레이션/1회 강화/수집 부족/저장 실패/기둥 빗맞힘/정산 대기 경합을 자동 테스트한다. PC 실제 브라우저에서 폭파 5회 후 107개 수집, 80부품 강화 구매와 일반 맵 전환을 확인했다. 기존 입력 28개 회귀 테스트로 PC 즉시 사용, 터치 릴리스, 두 손가락 취소를 검증한다. 실제 휴대폰 기기 테스트는 별도로 필요하다.
