# Godot 0.5.9 free web implementation plan

**Goal:** Replace the canonical public free game with a Godot 0.5.9 free edition, retaining access scope and old progress while enabling final automatic collection and unlimited upgrades.

**Architecture:** A separate checked-in project at `demos/planet-patchup/godot-free/`, copied from frozen paid 0.5.9, with explicit free access/data and browser migration adapters. A Vite-bundled browser shell retains existing telemetry and feedback; a local Godot export builder packages gzip WASM/PCK for Cloudflare Pages and feeds the canonical route generator.

**Tech stack:** Godot 4.6.2 Compatibility/single-thread Web, GDScript, Node 24/Vite, original FreeAnalytics transport, Cloudflare Pages.

## Global constraints

- Exactly eight maps: `arch-0-arch-quarter-v2` tutorial and `arch-1-arch-quarter-v2` through `arch-7-arch-quarter-v2`; seven playable sites, with the last boss. No paid region map may be packaged or started through any entry/import path.
- Six normal map records >=70% unlock the boss. Restoration is six distinct normal best records >=70% plus boss clear, seven steps; tutorial/replay do not add steps. Content purchase/access remains separate from restoration.
- Only `aftershock`, `relay`, `orbital`; one passive and one active slot forever. Five other region previews remain visible/locked as in the published free version. No paid skill definitions or paid regional content may ship.
- Central automatic collection uses approved paid 0.5.9 behavior: starts 1 second after exhaustion, completes within max 9 seconds total; replacement debrisProcessing/salvageYield upgrades and unlimited existing upgrades/skills, historical costs preserved, old collection tracks refunded exactly once with an archived ledger.
- Preserve v5 94 BPM music and audio toggles. Preserve old profile balances/ownership/records/history/tutorial progress. Legacy localStorage remains untouched, including raw malformed/conflicting input. Separate Godot free storage; migrate only when no free Godot slots exist.
- Support valid legacy v1 and v2 saves including `arch-campaign-v0.2.2` wire tag and `arch-campaign-v0.2.3` exported profiles. Reject other campaigns/paid content and corrupted ledger data; show recovery notice and do not silently overwrite/reset.
- Paid Godot 0.5.9, original paid Phaser app, saves and unrelated dirty main changes stay unchanged.
- User performs all gameplay/device/web/feel/thermal testing. No tests, scenes, gameplay/replays, browser or device-app launches. Allowed: source review, compile-only Godot checks, imports/exports, syntax checks, static file/HTTP verification and deployment. Report those boundaries.
- All uploaded files <=25 MiB. Store gzip bytes under versioned .wasm/.pck names with exact Content-Encoding:gzip, appropriate MIME and no-transform headers; verify decoded HTTP hashes after deployment. Keep old Phaser hashed assets/map editor and an archival free entry.
- Canonical public URL remains `/planet-patchup/play/`, generated through `scripts/planet-routes.mjs` / `sync-planet-routes.mjs`.
