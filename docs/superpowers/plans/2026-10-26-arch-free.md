# Arch Quarter Free Campaign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ship the first Arch Quarter campaign in the free web game, with automatic collection, the approved economy and a useful local playtest journal.

**Architecture:** New `src/arch` modules isolate the campaign from legacy free saves and comparison editions. The free build boots an Arch entry while the other builds retain their old entry. Reuse accepted structural physics and existing destruction effects, adapting them to the campaign's purchases and counters. Use a bounded local journal and explicit JSON export; the user explicitly chose local-only records on 2026-10-26.

**Tech Stack:** JavaScript modules, Phaser/Matter, Vite, node:test, localStorage.

## Global Constraints

- Preserve previous map definitions, comparison builds, physics and save keys. New save namespace and balance/map versions.
- First region: six ordinary maps with exactly 2000, 2400, 2800, 3200, 3600, 4000 occupied pixels and one 6000-pixel boss. Cement/stone, arches, warm cream/terracotta/blue; no water or vegetation.
- Column/body/roof role metadata for every occupied pixel, stable unsupported joints and playable blast targets.
- All six ordinary maps open. Boss opens only after each has a best result >=70%; entry is manual. Continue at70% and record100%.
- Normal reward = collected loose pixels only. Boss reward = first success4000, repeat1000, fail0; never add boss debris as currency. Settlement idempotent.
- Collection:20 pixels every0.25s atbase; upgrades+2batch and-0.01s cadence. No collection range. Loose pixels rise and disappear, never collect solid chunks. Exhaustion allows up to10s and secures all remaining eligible loose pixels; pause does not advance it.
- Follow `simulation/campaign-plan-v0.2/config.json` and `docs/campaign-balance-v0.2.md` for numbers. These are hypotheses, not a validated30min claim.
- New player-facing map and skill names in English. Keep mobile input modes and PC behavior.
- Journal automatic per run, bounded, versioned, exported on demand. Include failures/abandonments, upgrades, attacks, collection, time, map seed/version and performance, without personal information.
