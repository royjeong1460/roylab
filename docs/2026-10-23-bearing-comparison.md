# 기둥 두께·하중 비교판

URL: /games/planet-patchup-bearing/

기존 motion/support/ideas/무료/유료 배포물은 변경하지 않는다. 실험 옵션과 화력, 낙하 설정도 bearing 전용 키로 저장하며 기존 저장값을 읽거나 덮어쓰지 않는다.

## 조작과 맵
- `하중 비교 시작`: 외력 없이 두 시험체의 현재 지지력을 평가한다. 재시도는 `다시 테스트`.
- 폭파와 블랙홀도 기존처럼 사용 가능. 공격 시 지지력을 다시 평가한다.
- 첫 맵: 같은 상부 건물, 왼쪽 1칸 / 오른쪽 2칸. 회전 반응 기본3배, 중력1배, 속도 상한1배.
- 단독1칸 / 단독2칸: 모바일에서 확대 비교.
- 중앙 하중: 양쪽 모두 버틴다.
- 무거운 중앙 하중: 1칸 압축 붕괴 / 2칸 유지.
- 두 시험체 간격120칸. 먼저 쓰러진 시험체가 다른 쪽을 때려 비교를 오염시키지 않도록 조정했다.

## 게임용 지지력 모델
동일한 픽셀은 동일 질량으로 본다. 수평 단면 위쪽의 연결된 픽셀 수가 하중이며, 좌표 평균이 무게중심이다. 기둥 자체의 상부 질량도 포함하므로 2칸 기둥의 총 하중은 1칸보다 조금 크다.

- 남은 유효 두께: 실제 수직 연결 픽셀의 `1 - bondDamage` 합.
- 휨 저항: 연속한 받침 구간별 유효 두께 제곱의 합. 빈 간격을 재료 두께로 세지 않는다.
- 편심: 무게중심이 받침 바깥으로 벗어난 거리.
- 부담 = `하중 / (800 × 유효 두께) + 하중 × 편심 / (3500 × 휨 저항)`.
- 실제 중력 배수를 부담에 곱한다. 기준은 기존 .00007 중력값이다.
- 부담100% 초과: 편심이 있으면 기존 Matter 힌지로 기울어지다 연결이 끊어진다. 중앙 압축 과부하는 짧은 받침 구간을 픽셀화해 실제 낙하 틈을 만든다.
- 처음 설계된 두께 비율에 의존하지 않는다. 2칸을 잘라 1칸만 남겨도 같은 남은 두께로 계산한다.

실제 재료의 탄성·좌굴·유한요소 해석은 아니다. 강도800/3500은 비교용 게임 조정값이다. 복잡한 여러 기둥 구조의 상세 하중 분배는 단순화되어 있으며, 본 비교판의 정적 지지 평가에만 적용한다. 동적 조각끼리의 충돌과 파괴는 기존 방식이다.

## 확인
- bearing 테스트8개 통과: 두께/하중/편심/결합 손상, 같은 상부 형태, 절단 후 남은 두께, 중앙 압축 붕괴, 1200프레임 비교 오염 방지, 중력 배수와 저장 격리.
- 기존 support8개, motion8개 테스트 통과.
- 별도 리뷰: 5개 맵에서 각900프레임 반복 폭파, 유한한 물리값과 픽셀 수 보존 확인.
- 로컬 브라우저에서 하중 시작, 맵 선택, 단독2칸 유지와390×844 화면 배치를 확인.
- 실제 iPhone 터치/성능과 큰 실전 맵의 균형은 별도 플레이 테스트가 필요하다.
