# 스킬 범위 성장·후반 가격 · 2026-11-16

사용자는 제안된 수치를 승인했다. 후속 폭파10렙, 나머지 파괴 스킬5렙 이후 S=1+0.04sqrt(L-M)로 실제 범위를 계속 키운다. 기존 위력 성장과 낮은 레벨의 효과, 발동 타수, 지속/지연/간격, 폭발/투하/파동/표적 수는 유지한다. 배터리 충전은 효과·가격 모두 그대로다.

후속 폭파2.5S, 릴레이3S, 내리찍기 포착범위(현재 충격범위 기반)S, 압력확산11S/마지막2S, 지면파동8S/간격7S, 궤도낙하3S/5S, 지진 타격폭1.2S/손상9S/주변밀기12S, 중력압박 접촉2.5S, 음파 타격5S/탐색폭S가 실제 적용부로 전달된다. 내리찍기는 넓어진 포착 영역의 원래 픽셀 ID들을 끝까지 추적하며 별도 하강 재포착은 추가하지 않는다. 기본 레벨 데모와 원본 자산은 유지한다. 설명에 현재·다음 범위를 표시하고 기존 이펙트 크기를 실제 판정에 맞춘다.

후속 폭파의 배치는 기존 간격5를 유지해 같은 시드의 중심 선택을 보존한다. 궤도 낙하는 보통 반경에서 기존 native 조회를 사용한다. 매우 큰 허용/가져오기 레벨에서는 동일 좌표 조건으로 실제 재료점만 조회해 빈 열 수백만 개를 탐색하지 않는다. 논리 반경과 기존 native 바이너리는 그대로 유지한다.

기존 학습·고정 가격표·첫 연장 가격A는 보존한다. 이후 새 구매는10ceil(A[1+0.03(L-M)]/10), 정확한 정수 연산과10단위 올림이다. 현재 레벨40의 다음 가격: 후속41,010 / 릴레이·지진44,240 / 내리찍기29,500 / 확산39,340 / 지면49,160 / 궤도88,480 / 중력59,000 / 음파73,740. 배터리 충전은 기존 가격. 과거·혼합 구매 기록은 원래 polynomial 상한과 기존 하한을 사용해 받아들이며 지출·잔액·레벨을 다시 계산하거나 환불/초기화하지 않는다. 저장 스키마·구매 트랜잭션은 변경하지 않았다. 원래의 보수적인 장부 범위를 유지하는 것이며 실제 저장 불러오기 검증은 아니다.

스킬별104레벨의 원식 산술, 낮은 레벨/위력/횟수/시간 보존,9,009 가격점,10,303 과거→새 가격 전환 합계, 희소 좌표 조건 동등성, 원본맵43/자산683, 소스·PCK·압축 해시 및 서명을 확인했다. 독립 가격 검토·전체 소스 검토PASS. 초기 컴파일에서 찾은 들여쓰기는 수정 후 import/compile/export/Xcode를 다시 통과했다. iPhone0.5.71(81) 업데이트 설치 완료, 앱 실행 없음. Web 공개 전달 상태는 delivery.json에 별도로 기록한다.
