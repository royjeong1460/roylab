# 장착 상태와 일시정지

- 스킬 카드: 오른쪽 민트색 버튼 안에 ‘장착 중’을 중앙 정렬한다. 채워진 슬롯과 버튼의 체크는 삭제하고, 빈 슬롯 및 잠금·교체·해제 동작은 유지한다.
- 진행 중 일시정지: 이어하기 → 다시하기 → 회수 → 옵션·피드백 순서. 회수 중에는 이어하기와 보조 동작만 남는다. 버튼의 최소 높이는 44. 카드 크기는 안전 영역과 줄바꿈 후 콘텐츠 높이를 따른다.
- 다시하기·조기 회수 확인, 슬롯 교체, 기록 관리 등에 쓰는 공용 창도 본문에 맞춘다. 스킬 시연·라이선스 등 긴 내용은 스크롤로 읽는다. 경관 보상 및 확대 전 경관 창은 그림과 조작에 맞추고 확대 모드와 전체 갤러리는 유지한다.
- [390×844 동일 조건의 정적 배치 비교](layout-comparison.html). 실제 캡처나 플레이 검증이 아니다. 실행 확인은 사용자 담당.
