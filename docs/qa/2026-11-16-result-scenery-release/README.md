# BUG-024 · 현재 맵의 결과 경관 · 2026-11-16

청소 결과가 이전 Arch 전용 기물 배경을 사용하던 연결을 제거했다. 현재 `receipt.siteId`의 카탈로그 메타데이터와 방금 달성한 `receipt.ratio`를 기존 `CultureBackdrop`에 전달한다. 플레이와 같은 문화권 경관·일반/보스 crop·지형·쓰레기·하늘/날씨를 재사용한다.42개 일반/보스 캠페인 결과에 연결하고 튜토리얼은 기존 플레이 배경의 fallback을 유지한다. 유효한 맵 정보가 없는 결과는 다른 맵 그림으로 대체하지 않는다.

70%미만에는 쓰레기,70%이상에는 남은 쓰레기와 복원 경관, 정확히100%에는 쓰레기가 없는 상태다. 현재 시도 결과를 사용하며 최고기록·업적 해금 조건을 변경하지 않는다. 일반6맵+보스 모두100%에서 문화권 전체 그림을 얻는 기존 규칙은 별개로 유지한다.

150px 결과 미리보기와 캡션을 유지하고 지형 하단을 기준으로 작은 배경 영역을 보여준다. 카탈로그 metadata만 복사한 가벼운 Node2D를 사용한다. 파괴용 World·물리·픽셀 배열·맵 캐시 확대는 생성하지 않는다. 메뉴 위에 보이도록 배경의 z-index를0으로 조정하고, 클립·resize 변환을 연결했다. 결과 미리보기의 날씨는 정지 이미지로 표시한다. 결과창과 함께 자식 노드가 해제된다.

기준 iOS0.5.67(77) 원본 후보, 맵43개·자산683개, 게임 물리·경제·진행·사용자 저장·업적·폰트·크레딧·스킬 시연·플레이 배경 코드는 동일하다. 공통 변경은 app/screens.gd와 presentation/environment_receipt.gd 두 파일이며 Web의 음악·앱 어댑터·엔진·코어는 유지한다.

Godot import/compile-only/export, geometry43건·0/70/100상태, 양쪽 PCK10개 공유 payload·문화권 텍스처6개, Xcode Release·deep/strict서명을 확인했다. 독립 소스 검토에서 blocking issue는 없었다. 사이트 빌드·iPhone 업데이트 설치·공개 Web 전달은 [delivery.json](delivery.json)에 실제 결과만 기록한다.
