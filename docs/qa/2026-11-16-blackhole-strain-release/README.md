# 블랙홀 고정 구조물 손상 조정 · 2026-11-16

사용자는 블랙홀이 강하다고 느낀 구간이20렙이라고 확인했고, 조사 후 고정 구조물 손상만 하향하는 안을 승인했다. 기준0.5.71(81)은 같은 턴에 승인·배포한9개 스킬 범위와 미래 가격 변경을 포함한다. 최종0.5.72(82)는 그 위에서 blackhole_physics.gd의 두 호출값만 바꾼다.

활성 시 strain_supported계수1.4→1.0, 이후0.2초마다.6→.3.20렙의 실제power.4·지속4초에서 초기.56→.4, 반복.24→.12. 완전한4초를 가정한 명목20회 반복 입력 합계는5.36→2.8(약47.76% 감소)다. 이는 소스 일정 산술이며 실제 타격 수·파괴 픽셀·성능·균형을 측정하거나 예측한 값이 아니다. 그룹 재선택·지형·이미 손상된 결합 상한·뒤따르는 접촉에 따라 달라진다.

충격파는 직접반경5/halo13.4/충격도달28·12에너지이고 단발 파괴 및 패시브 카운터를 진행한다. 블랙홀은반경40에서 고정그룹의 좁은 지지부를 반복 재탐색하고, 분리 후 흡입·혼합·분쇄가 이어지며24에너지다. 서로 다른 power계수의 숫자 자체를 도구 위력비로 비교하지 않는다. 이번에는 충격파를 조정하지 않았다.

흡입·반경/지속시간/혼합/분쇄 성장과 가격·24에너지 비용·물리커널·맵43/자산683·기존 스킬 성장·새 가격·저장/원장은 기준판 그대로다. 소스 1,447개 파일 비교와 두 줄의 정확한 차이, 독립 검토, native/Web compile/export/Xcode/서명 및 PCK 비교를 확인했다. 기본 동작을 바꾸거나 앱을 삭제하지 않고 같은ID에 업데이트 설치한다.

이 최종판에 포함된 [스킬·가격 적용 기록](../2026-11-16-skill-range-release/README.md). 기본 이전판0.5.70(80), 직접 롤백0.5.71(81)과 해당 immutable Web 패키지를 보존한다. 공개 전달 상태는 delivery.json/HTTP 증거에 기록한다. 게임·테스트·씬·시뮬레이션·브라우저·기기 앱 실행 없음. 실제 느낌·성능·저장/구매 확인은 사용자 담당이다.
