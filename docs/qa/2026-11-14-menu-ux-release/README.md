# 전체 메뉴·플레이 흐름 업데이트 · 2026-11-14

오늘 채택한 모바일 메뉴와 결과·강화·장착 흐름을 실제 Godot Web과 iOS에 함께 반영했다. 로컬 HTML 시안의 예시 가격과 진행은 복사하지 않고 기존 offers, Money, 기록, 진행 API에 연결했다.

| --- | --- |
| 시작 | 기존 사막 행성·회전·폐위성·작은 행성 유지, 보유 고철과 간결한 메뉴, 모바일 폭 중앙 정렬 |
| 구역 | 기존 복원 썸네일 6개, 열림·미발견 상태, 실제 진행에 따른 선택 |

## 보존한 동작

장착 해제는 상세 화면의 명시적 행동으로만 한다. 실제 구매의 revision/cost/level 가드와 Money 정수 계산, 튜토리얼 첫 강화와 건너뛰기, 기존 광고 경계, 새 복원 그림 보상을 유지한다.

수거 후 기존 `journey.finish`의 원자적 정산을 그대로 호출한다. 화면 열기·탭 변경·결과 상세·출발에서 고철을 지급하지 않는다. 저장에 실패하면 현재 판을 유지해 재시도한다. 다시하기는 현재 미정산 판만 기존 abandon/seal로 마무리하고 같은 맵을 새로 시작한다. 저장된 체크포인트·최고 기록·장비·보유 고철은 유지한다.

Web의 저장 이전·오류 안내·피드백·텔레메트리와 native의 광고·문서 연결을 보존했다. native에 새 피드백 서비스나 Web 광고를 추가하지 않았다. Web 피드백은 옵션·일시정지·결과 상세에서 접근한다.

기존 맵 43개, 원본 자산 681개와 경제·진행·저장·물리·플레이뷰 소스가 동일함을 해시로 확인했다. 오늘 앞서 웹 공개가 막혔던 문화권 배경 연결도 이 패키지에 포함한다.

## 확인 범위

Godot import·compile-only·export, Web 압축 전후 해시와 PCK 메뉴 모듈, Next 정적 사이트 webpack 빌드, Xcode Release와 deep/strict 서명을 확인했다. iOS **0.5.64(74)**는 기존 앱 ID와 저장을 유지하며 삭제·초기화·실행 없이 업데이트 설치했다(설치 순번 4964). Web 공개 전달 상태는 [delivery.json](delivery.json)에 별도로 기록한다.

게임·씬·시뮬레이션·자동 리플레이·브라우저 게임·기기 앱은 실행하지 않았다. 실제 가독성·터치·결과·재시작·상점·저장·광고·음악·발열은 사용자 확인 대기다.

## 사용자 확인 순서

1. 시작→구역·맵→플레이. 일반 6개와 보스·잠금·이전 기록 표시.
2. 배터리 소진→수거→결과가 붙은 강화. 고철이 한 번만 증가하는지.
3. 도구·스킬·보조 탭, 습득·강화·장착·교체·해제. 최대 2+2칸과 초기 잠금 상태.
4. 다시 도전·다음 맵·일반 6의 보스·보스 다음 지역·마지막 보스. 첫 튜토리얼 강화와 건너뛰기.
5. 일시정지 취소·옵션 복귀·확인 후 다시하기·청소 마치기. 수거 중 일시정지와 저장 실패 복귀.
6. 업적 부분·완전 경관·보상 팝업, 언어·음량·화면 톤, 기존 저장 유지.
