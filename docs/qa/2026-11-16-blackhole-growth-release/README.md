# 블랙홀 연속 성장·흡인력 분리 · 2026-11-16

사용자는 범위·지속시간은20렙 이후에도, 코어 혼합은36렙 이후에도 실제 해당 효과가 조금씩 계속 늘어나며 위력은 흡인력 강화에서만 올라가도록 요청했다. 기존 강화 레벨·가격·거래 기록과 저장을 유지하고 파생 값만 변경한다.

범위는20까지30+0.5L, 이후40+0.25(L-20)칸. 지속시간은20까지2+0.1L, 이후4+0.05(L-20)초. 코어혼합은36까지1+0.25L, 이후10+0.125(L-36)이다. 고정값으로 멈추지 않고 계속 성장하며 새로운 레벨 상한은 없다. 기존 숫자 안전 한계 검사는 유지한다.40렙에서45칸·5초·혼합10.5,60렙에서50칸·6초·혼합13이다.

이전의 같은 레벨 조합 흡인력 곡선을 wellPull로 이관했다. P(F)=(1+0.08√max(0,F-20))²×(1+0.08√max(0,F-36)), B(F)=(1+0.05min(F,30))×(1+0.08√max(0,F-30)), 표시 흡인력=B(F)P(F), 실제 gravityPower=0.2×표시흡인력이다. 압력은 오직 흡인력 레벨F에서 구한다. 모두40의 기존 gravityPower1.3397565144는 유지한다. 범위·시간·혼합의 레벨이 다른 기존 세팅은 역할 분리에 따라 파생 흡인력이 달라질 수 있으나 저장된 레벨·소비 고철을 바꾸거나 환불/리셋하지 않는다.

coreMix는values.mix를 그대로 사용하고 min36클램프와 혼합초과분의 globalpressure 전환을 제거했다. 예전 혼합40의 UI값은11.6이었지만 실제는10이었다. 이제 UI와 실제값이10.5로 일치하므로 표시가 내려가 보여도 실제 혼합계수는 높다. 혼합은 의도한 국소 휘젓기/제동/안쪽가속 효과를 높인다. 네이티브 core_impulse는power×mix를 사용하며10으로 제한하지 않는다. 범위·시간·혼합에서 global gravityPower나 지지대손상 계수로 추가 배율을 보내지 않는다는 뜻이며, 더 넓고 오래 작용하고 강하게 섞이는 물리적 결과까지 같다는 뜻은 아니다.

강화 비교·설명·숫자 한계 검사는 증가하는 실제 값을 사용한다. 변경은campaign/economy.gd와app/workshop_menu.gd뿐이다. 이미 채택한 충격파 성장식과 모든 그 외 트랙, 마모, 스킬, 배터리, 도구비용, 가격·원장·프로필스키마, 맵43/자산683, 실제 World/커널/이펙트, 결과 경관·폰트·크레딧을 유지한다. 기존 출동 연결Journey.stats→Worldwell→blackhole_physics→core_impulse와 이펙트의 실제반경/잔여시간 경로를 검토했다. 기존 몸체 속도 안전 제약은 유지한다.
