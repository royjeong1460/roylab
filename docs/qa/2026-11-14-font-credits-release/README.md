# 선택 폰트·제작 및 도움 · 2026-11-14

승인된 1번 NeoDunggeunmo Pro1.020을 공통 UI 글꼴로 적용했다. 기존 글자 크기·색상·배치와 메뉴/결과 흐름을 유지했다. 폰트 원본과 SIL OFL1.1 고지를 보관했다. 미지원 화살표 등은 기존 엔진 글꼴 대체 설정을 사용한다. 실제 Godot 렌더링은 사용자 확인 대기다.

옵션의 `제작 및 도움`에 Roy, 활성 폰트, Godot·godot-cpp, 각 플랫폼에서 사용하는 연동, Aseprite와 Codex 제작 도움을 모았다. `라이선스 보기`에서 항목을 고르면 원문을 스크롤·선택하고 목록으로 돌아갈 수 있다. 라이선스 뷰어와 기존 팝업의 닫기·포커스 순환을 연결했다. 자동 엔딩 화면은 추가하지 않았다.

포함된 구 Galmuri, iOS 플러그인에 포함된 Noto도 원문 고지를 보존했다. JSON에 원문을 넣어 iOS와 Web PCK가 오프라인에서도 고지를 포함한다. Godot MIT·제3자 고지·godot-cpp·Poing·Noto·Neo·Galmuri·Google Swift 래퍼 고지를 포함한다. Google 바이너리 SDK를 래퍼의 Apache 라이선스로 표시하지 않으며 제공자 정보와 구분했다. PostHog는 웹 연동, Aseprite·Codex는 제작 도움으로 표시한다. 미채택 PixelFX·연구용 폰트·미사용 개발 의존성은 제외했다. [실제 포함 자료 감사](credits-audit.md)와 [원문 해시](credits-provenance.json)를 보관한다.

기준 iOS0.5.66(76)의 자산681개·맵43개·기존 후보, 경제·진행·저장·게임 물리·효과·음악·10개 스킬 설명 시연은 해시가 같다. Web의 MP3 음악 경로·앱 어댑터·엔진·코어를 유지했다. 글꼴·메뉴·고지 외 게임 동작은 변경하지 않았다.

Godot import/compile-only/export, 양쪽 PCK의 글꼴과 원문 JSON 바이트, Xcode Release·deep/strict서명, 사이트 빌드 확인. iOS0.5.67(77)은 앱 ID와 사용자 저장을 유지해 업데이트 설치했다(설치 순번5012). 앱은 실행하지 않았다. 웹 공개 전달은 [delivery.json](delivery.json)과 정적 HTTP 증거에 별도 기록한다. Godot 게임·씬·테스트·브라우저 게임·기기 앱 실행과 플레이 검증은 하지 않았다.
