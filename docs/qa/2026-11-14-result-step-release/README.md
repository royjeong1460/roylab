# 결과 확인 후 강화 · 2026-11-14

사용자가 결과와 강화가 한 헤더에 섞인 구성을 취소하고, 기존 결과 화면을 재활용해 한 템포 쉬어가는 흐름을 승인했다.

**플레이 → 수거·정산 → 결과 → 강화 또는 재출발**로 변경했다. 결과에서 자동으로 강화나 다음 맵으로 넘어가지 않으며, 별도 대기 시간도 강제하지 않는다.

- 결과 화면은 기존 회수율·획득 고철·보너스·해금 안내·첫 문화권 복원 풍경을 재사용한다. 보스 결과에는 기존 지역 진행 정보를 표시한다.
- 하단에 **장비 강화**를 우선 표시하고, 실제 진행에 맞는 다음 맵·보스·다음 지역·행성 복귀 또는 재도전과 맵 선택을 제공한다. 중복 재도전·첫 강화 버튼은 줄였다.
- 강화 헤더는 **강화 / 보유 고철**만 남겼다. 고철 아이콘을 숫자 옆에 붙였고, 지난 맵·회수율·획득량 서브라인은 제거했다.
- 강화 하단의 **상세 결과**는 같은 판의 결과 페이지를 연다. 화면·시스템 뒤로가기와 강화 버튼으로 돌아가면 보던 탭·도구·스킬 종류·스크롤 문맥을 보존한다.
- 결과의 새 스킬 해금 안내를 거쳐 강화로 이동할 때도 실제 결과를 유지한다. 업적 경관과 복원 보상 팝업의 돌아갈 화면도 결과로 연결한다.
- 다른 메뉴·장착 슬롯·강화 카드·일시정지 흐름, 원본 아트·맵·물리·경제·저장 경로·광고·웹 연결부는 유지했다. 보상은 기존 `journey.finish`에서 한 번만 정산하며 결과 다시 보기와 화면 이동에서는 지급하지 않는다.

## 검증과 전달

Godot import·compile-only·export, Web 패키지의 압축 전후 해시, iOS Xcode Release·deep/strict 서명을 확인했다. 기존 맵 43개·원본 자산 681개와 경제·진행·저장·물리 소스가 기준판과 동일하다. Web app은 `finish_run`과 시스템 Back 두 함수만 바뀌며 나머지 브리지·저장 이전·피드백·텔레메트리는 동일하다.

iOS **0.5.65(75)**는 기존 앱 ID·저장을 유지해 업데이트 설치했다(설치 순번 4972, 실행 안 함). Web 최종 패키지의 공개 상태는 [delivery.json](delivery.json)에 별도로 기록한다. 이전 iOS0.5.64(74)와 Web `free-0541-468c4227e5a1` 패키지를 보존했다.

게임·테스트·씬·브라우저 게임·기기 앱을 실행하지 않았다. 실제 시각·터치·플레이·광고·저장 복귀·발열은 사용자 확인 대기다.

## 사용자 확인

1. 수거가 끝나면 강화에 바로 들어가지 않고 청소 결과가 나오는지.
2. 결과의 회수율·획득 고철을 보고 강화 또는 다음 맵·재도전을 선택할 수 있는지.
3. 강화에는 보유 고철만 보이고, 상세 결과→뒤로가기에서 보던 탭으로 돌아오는지.
4. 새 스킬 해금 안내→강화→상세 결과와 업적 왕복에서도 같은 결과가 유지되는지.
5. 튜토리얼 첫 강화·실패 결과·일반6·보스·마지막 보스와 기존 저장이 유지되는지.
