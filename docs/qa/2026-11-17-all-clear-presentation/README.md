# 결과 경관 자막과 올 클리어 표시

호박빛 노점 100% 결과, 390 논리 픽셀 기준. 기존 창은 경관과 자막을 같은 Control에 놓고 높이에서 각각 24, 20을 빼서 배치했다. 첨부 결과에서 경관 하단이 글자의 위를 덮었다. 새 창은 최소 124px인 경관 전용 클리핑 영역, 4px 간격, 최소 22px인 자막으로 구성한다. 스크롤 시에도 두 행은 같은 컨테이너에서 배치된다.

결과 왕관은 이번 출격의 allClear, 맵 선택의 왕관은 해당 현장의 최고 회수율 100%, 시작·지역 선택의 왕관 배지는 지역 내 일반 6곳과 보스의 완전 복원에 따른다. 맵 선택에서 70% 클리어는 민트색이며 100% 행만 금색 왼쪽 선과 왕관 배지가 붙는다. 실제 게임 화면 확인은 사용자 담당.
