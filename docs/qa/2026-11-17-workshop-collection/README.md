# 강화 버튼과 수집 마무리 · 2026-11-17

도구·스킬·보조 장비 카드의 반복 부족 문구를 제거하고 설명 아래에 강화/가격 버튼을 가운데 놓는다. 상세창도 가격은 구매 버튼에만 표시한다. 잔액 검사·가격·저장 방식은 변경하지 않는다.

현재 출동의 최종 회수 등급으로 추가 대기를 결정한다. 70% 미만 0초, 70~99% 0.5초, 전량 회수 1초. 추가 시간 동안 회수율과 기존 연출을 밝게 유지한 뒤 종전 0.5초 페이드로 결과/보스 경로에 진입한다. 정지 중엔 대기도 멈춘다. 물리, 등급 이벤트, 보상, 사운드를 다시 실행하지 않는다.

기존 아이콘은 유지했다. 앱 설치·정적 웹 전달은 delivery.json에 기록하며 플레이와 체감은 사용자 확인 대상이다.
